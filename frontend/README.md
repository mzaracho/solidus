# HealthOps Frontend

## What it contains and what it is used for
The HealthOps frontend is the client-facing application used by clinic staff and professionals to manage their daily operations. It consists of interactive web interfaces for tracking sessions, managing patient records, reviewing fee settlements, and configuring system profiles.

## Tech Stack
- Framework: Next.js + React.js
- Styling: Tailwind CSS
- State Management & Fetching: Zustand + TanStack Query
- UI Components: Radix UI

## Main Dependencies
- next, react, react-dom
- @tanstack/react-query
- zustand
- tailwindcss, lucide-react, date-fns

## Basic Installation
1. Install dependencies: `npm install`
2. Set up environment variables
3. Run the development server: `npm run dev`
4. Compile for production: `npm run build`
