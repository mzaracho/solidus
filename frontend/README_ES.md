# HealthOps Frontend

## Qué contiene el código y para qué se utiliza
El frontend de HealthOps es la aplicación web interactiva utilizada por el personal y los profesionales de la clínica para gestionar sus operaciones diarias. Dispone de interfaces web para reportar sesiones, gestionar historiales de pacientes, visualizar las liquidaciones de honorarios y adecuar perfiles del sistema.

## Stack Tecnológico
- Framework: Next.js + React.js
- Estilos: Tailwind CSS
- Manejo de Estado y Peticiones: Zustand + TanStack Query
- Componentes UI: Radix UI

## Dependencias principales
- next, react, react-dom
- @tanstack/react-query
- zustand
- tailwindcss, lucide-react, date-fns

## Instalación básica
1. Instalar dependencias mediante NPM: `npm install`
2. Configurar el archivo de variables de entorno
3. Ejecutar el entorno de desarrollo: `npm run dev`
4. Construir la versión de producción: `npm run build`
